# wargames

WWII Campaign Tactics: a linked WWII campaign of real-time-with-pause tactical battles, fed by a HOI4-style war economy. Built with Godot 4.7.

- Design and build plan: [PLAN.md](PLAN.md)
- Current status: [PROGRESS.md](PROGRESS.md)

Run the game with `godot --path .`. Run the tests with `GODOT_BIN=/path/to/godot ./run_tests.sh`.
